# suryanshgupta9933.github.io

The source of [suryanshgupta9933.github.io](https://suryanshgupta9933.github.io).

Posts are markdown files under `blog/`, named `YYYY-MM-DD-slug.md`. `index.md`
is the landing page. GitHub Pages' default Jekyll build renders them — there is
no config file and no theme to maintain.

A post is one file. To add one: drop it in `blog/`, add a line to `index.md`.
